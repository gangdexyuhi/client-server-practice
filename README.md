## Состав репозитория

| Папка | Практическая работа |
|---|---|
| `practice_01_client_server/` | №1. Инициализация базы данных SQLite |
| `practice_02_client_server/` | №2. Базовые CRUD-операции через консоль |
| `practice_03_client_server/` | №3. Подключение Flask и первый маршрут |
| `practice_04_client_server/` | №4. Интеграция Flask и SQLite (чтение данных) |

| `practice_07_client_server/` | №7. Мини-проект «Список задач» (итоговая работа) |

В каждой папке:

- `отчет_ПР…pdf` — отчёт по работе;
- `src/` — исходный код;
- `screenshots/` — скриншоты работы приложения.

## Запуск

```bash
cd practice_07_client_server/src
pip install -r requirements.txt
python init_db.py      # создать базу (если её нет)
python app.py          # запустить сервер
```

После запуска открыть в браузере http://127.0.0.1:5000

Консольная версия (работы №2 и далее): `python crud_console.py`
